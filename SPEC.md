
### Общий архитектурный план (Дорожная карта)
Без разделения на задачи

**0. начальная настройка**

* Docker, CI/CD
Автоматическое развертывание


**1. Базовый Асинхронный API (Ядро)**

* API Gateway & Auth: Единая точка входа, маршрутизация запросов. Авторизация через JWT, ролевая модель (Админ, Клиент, Курьер).

* Сервисы каталога, корзины и управления профилями. Добавление в корзину.

* PostgreSQL для реляционных данных S3 (MinIO) для изображений товаров.


**2. Транзакции (Заказы и Оплата)**

* Внедрение Apache Kafka / RabbitMQ.
Общение сервисов через события без прямого ожидания ответов

* Паттерн Saga, механизм надёжной покупки.
* Биллинг и Идемпотентность: Надежное списание бонусов, оформление заказа, защита от двойных списаний.


**3. Скорость и Отказоустойчивость (HighLoad)**

* Redis для хранения пользовательских сессий, корзин и горячих данных каталога
* Event Sourcing: Хранение истории баланса и заказов в виде неизменяемого потока событий (можно "отмотать")
* Защита API: Rate Limiting (лимиты запросов от спама) и Circuit Breaker (предотвращение каскадных падений микросервисов).

* ????? Разделение баз данных на чтение и запись?????


**4. Данные и Поиск (Data & Search)** Потенциальное улучшение

* Продвинутый поиск
Внедрение Elasticsearch для фасетной фильтрации, опечаток и синонимов.
Либо векторный поиск (Vector DB) для семантического поиска товаров (поиск по смыслу).

* Аналитическое хранилище (DWH)
Перенос логов и событий заказов из PostgreSQL/Kafka в ClickHouse для построения аналитики в реальном времени (например, дашборд нагрузки на платформу).

* Рекомендательная система: Микросервис, предлагающий товары на основе совместной фильтрации (покупок похожих пользователей).


**5. Логистика и Гео (Доставка)** Потенциальное улучшение

* Умный диспатчинг (Delivery Service): Назначение оптимального курьера, батчинг (объединение 2-3 попутных заказов для одного курьера). С учетом графа дорог, пробок и времени на сборку заказа.

* Real-time трекинг (WebSockets / gRPC): Отображение движения курьера на карте и моментальное обновление статусов для клиента.
